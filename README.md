# ResearchMind – Autonomous AI Research Agent

## Overview
ResearchMind is an AI-powered research assistant that discovers academic papers, retrieves relevant evidence, analyses research findings, identifies potential research gaps, and generates structured research reports with verifiable citations.

## Core Features
- Academic paper discovery
- Intelligent PDF processing
- Hybrid Retrieval-Augmented Generation (RAG)
- Evidence-based research analysis
- Multi-agent orchestration
- Citation verification
- Research gap identification
- Automated report generation

## Technology Stack
- Python
- FastAPI
- React + TypeScript
- PostgreSQL
- Qdrant
- Sentence Transformers
- LangGraph
- Docker
